# io — Input/Output Layer

The `io` package provides data readers, data sources, and exporters for standardized experiment data handling.

## Module Overview

| Sub-module | Description |
|------------|-------------|
| `io.readers` | Data reader classes (CSV, JSON, Array, Synthetic) |
| `io.sources` | Data source abstractions (File, Stdin, Generator) |
| `io.exporters` | Result exporters (CSV, JSON, HTML) |
