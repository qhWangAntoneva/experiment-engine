# viz — Visualization Layer

The `viz` package provides renderers and dashboards for visualizing experimental data through various backends: Matplotlib, Plotly, Streamlit, and console.

## Module Overview

| Sub-module | Description |
|------------|-------------|
| `viz.base` | Abstract `Renderer` base class |
| `viz.matplotlib_renderer` | Matplotlib static image renderer |
| `viz.plotly_renderer` | Plotly interactive HTML renderer |
| `viz.console` | Rich terminal console renderer |
| `viz.streamlit_dashboard` | Streamlit interactive dashboard |
